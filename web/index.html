Model and execution limits

The action allowance pauses saved work; Resume gives a fresh allowance. Finishing uses no action. New installations allow 128 actions, 32,768 context tokens and 8,192 response tokens; saved preferences are preserved. Context budgeting uses a conservative estimate. Match these limits to your model.
