    Model and execution limits

    The optional action allowance pauses saved work; Resume gives a fresh allowance. Finishing uses no action. New installations leave it off, with 128 actions available when enabled, 32,768 context tokens and 8,192 response tokens; saved preferences are preserved. Context budgeting uses a conservative estimate. Match these limits to your model.

    Keep an AutoProteus tab open for unattended work. Closing every tab stops work and releases the local model and VM after about 5 seconds. Saved files remain.
